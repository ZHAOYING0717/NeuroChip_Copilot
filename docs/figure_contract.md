# Figure 1 contract

Core conclusion: The event-level pipeline reproduces published firing-rate and STTC values and detects controlled functional perturbations in group-held-out organoids.

Figure archetype: Quantitative grid with a dominant validation panel.

Target output: Competition technical report and Kaggle Writeup.

Backend: Python only (matplotlib).

Final size: 183 mm x 110 mm; SVG and PDF with editable text, 600 dpi TIFF, 220 dpi PNG preview.

Panel map:

- a: Out-of-fold ROC curve across 45 clean recordings and 135 perturbed counterparts.
- b: Anomaly-percentile distributions for clean, channel dropout, hyperactivity, and hypersynchrony.
- c: Identity plots comparing extracted firing rate and STTC with publisher source data for all 45 organoids.

Evidence hierarchy:

- Hero evidence: Group-isolated ROC and cluster-bootstrap 95% confidence interval.
- Validation evidence: Exact numerical reproduction of two published electrophysiology measures.
- Robustness: Three distinct event-level perturbation mechanisms.

Statistics:

- Biological unit: one organoid recording.
- Cross-validation: five-fold GroupKFold by source `fs_id`.
- Interval: 2,000 cluster-bootstrap samples at the organoid level.
- Baseline: clean held-out recordings.

Source data:

- Cross-validation predictions generated by `scripts/train_phenotype.py`.
- Feature comparison generated by `scripts/validate_source_data.py`.

Reviewer risks:

- Perturbations are synthetic and operate on detected spike events, not raw voltage waveforms.
- The reference cohort is a brain-organoid MEA cohort, adjacent to but not identical with every neural organ-on-chip design.
- The experiment validates anomaly sensitivity, not clinical or toxicological performance.

# Figure 2 contract

Core conclusion: A two-feature matched-control response magnitude tracks diazepam dose in four held-out brain organoids and is materially more transferable than an unpaired reference or the legacy timing-plus-burst model.

Figure archetype: Three-panel paired dose-response and ablation figure.

Target output: Competition technical report and Kaggle Writeup.

Backend: Python only (matplotlib).

Final size: 183 mm x 92 mm; SVG and PDF with editable text, 600 dpi TIFF, 220 dpi PNG preview.

Panel map:

- a: Observed ISI CV relative to each organoid's matched control across 0-50 uM diazepam.
- b: Leave-one-organoid-out response magnitude across dose, with cluster-bootstrap interval and treated-only blocked permutation test.
- c: Ablation comparing the primary two-feature timing model, legacy timing-plus-burst model, extended research set, single-feature models, and an unpaired training-control reference.

Statistics:

- Biological unit: one organoid; 19 conditions from four organoids.
- Cross-validation: LeaveOneGroupOut by organoid.
- Primary association: Spearman correlation between dose and response magnitude.
- Interval: 3,000 cluster-bootstrap samples at the organoid level.
- Permutation: 5,000 within-organoid dose-label permutations among treated conditions; zero-dose controls remain fixed.

Reviewer risks:

- The cohort contains only four organoids and one compound.
- Test treatment samples use their own held-out organoid's control, matching the intended paired assay workflow.
- The response magnitude is the validated endpoint for this model comparison and an auxiliary endpoint in the full intervention workflow; isotonic dose estimates remain exploratory.

# Figure 3 contract

Core conclusion: The simpler two-feature model improves internal held-out performance and, without retraining, distinguishes active perturbations in two independent 2D neuronal-culture domains.

Figure archetype: Three-panel quantitative validation grid.

Target output: Competition technical report, README, and Kaggle Writeup.

Backend: Python only (matplotlib).

Final size: 183 mm x 90 mm; SVG and PDF with editable text, 600 dpi TIFF, 220 dpi PNG preview.

Panel map:

- a: Legacy v1 versus primary v2 for leave-one-organoid-out dose Spearman rho and high-dose AUROC.
- b: Frozen-model response distributions for active pharmacology and negative-control wells in human iPSC-derived and rat 2D networks, using the first 180 s.
- c: Frozen-model response distributions for TTX and non-TTX wells in the same two domains, using the first 180 s.

Statistics:

- Internal biological unit: one organoid; 19 conditions from four organoids.
- External unit: one matched plate well; 66 well pairs in each stage comparison.
- External interval: 3,000 class-stratified bootstrap samples.
- External sensitivity analysis: repeat all comparisons with the first 600 s.
- Model state: frozen v2 artifact trained only on the Sharf diazepam organoid cohort.

Reviewer risks:

- External datasets are 2D neuronal cultures, not organoids or organ-on-chip devices.
- Both external domains come from one human plate and one rat plate; well-level performance is not a multi-site prospective validation.
- Active compounds and TTX test unsigned response transfer only; no external compound is mapped to a diazepam dose.
- The two external comparisons reuse wells and must not be counted as 132 independent preparations.
