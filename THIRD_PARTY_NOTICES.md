## Public data

- Naoya Itatani, *Spontaneous activity spike data and RNA-seq gene expression data from human forebrain organoids*, DOI 10.5281/zenodo.20286251, CC BY 4.0.
- Tal Sharf, *Extracellular Recordings from Human Brain Organoids Using High-density CMOS Arrays*, DOI 10.25349/D9031Z, CC0 1.0.
- Fikret Emre Kapucu, Andrey Vinogradov, Tanja Hyvärinen, Laura Ylä-Outinen, and Susanna Narkilahti, *Comparative microelectrode array dataset of functional development of human pluripotent stem cell-derived and rat neuronal networks*, DOI 10.12751/g-node.wvr3jf, CC BY 4.0.

The lightweight Demo event CSV is an attributed derivative of the first dataset. Derived drug-response summary files originate from the second dataset. External validation summary tables originate from the third dataset. Full source files are not redistributed in this repository.

OpenAI Codex assisted code development, testing, and documentation. The final application does not call an OpenAI or other external AI API at runtime. Every reported statistic is generated by the local, versioned pipeline.
