# Model artifacts

- `phenotype_model.joblib`: robust scaling, PCA, and Isolation Forest fit on 45 public forebrain-organoid MEA recordings.
- `drug_response_model.joblib`: matched-control response model fit on 19 diazepam conditions from four brain organoids.

Both files are generated by the repository scripts and exported with `scripts/export_public_assets.py`. Load only model files obtained from this repository or generated locally; Joblib files are Python pickles and must not be loaded from untrusted sources.

The models are research prototypes. They do not provide clinical, efficacy, or toxicological conclusions.
